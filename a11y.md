# a11y.md
> Accessibility specification for this project.
> Target: WCAG 2.1 AA compliance across all public-facing pages.

---

## Compliance Target

| Standard | Level | Applies to |
|---|---|---|
| WCAG 2.1 | AA | All public pages |
| WCAG 2.1 | AAA | Where feasible (contrast, captions) |

---

## Colour Contrast

| Use case | Minimum ratio | Token |
|---|---|---|
| Body text on surface | 4.5:1 | `--text-default` on `--surface-default` |
| Large text / headings | 3:1 | `--text-default` on `--surface-default` |
| UI components (borders, icons) | 3:1 | `--border-default` |
| Placeholder text | 4.5:1 | `--text-subtle` |
| Disabled text | No requirement | `--text-disabled` |

Verify contrast at every token change using: https://webaim.org/resources/contrastchecker/

---

## Focus Management

- All interactive elements must have a visible focus indicator
- Focus ring uses `--focus-ring-color`, `--focus-ring-width`, `--focus-ring-offset` tokens
- Never suppress focus with `outline: none` without a custom replacement
- Focus order must follow logical reading order (top-left to bottom-right)
- Modal/dialog: trap focus inside when open, return focus to trigger on close
- Skip-to-content link must be the first focusable element on every page

```tsx
// Required in root layout
<a
  href="#main-content"
  className="sr-only focus:not-sr-only focus:fixed focus:top-4 focus:left-4 focus:z-50"
>
  Skip to content
</a>
```

## Keyboard Navigation

| Key | Expected behaviour |
|---|---|
| Tab | Move to next focusable element |
| Shift+Tab | Move to previous focusable element |
| Enter / Space | Activate button or link |
| Escape | Close modal, dropdown, or drawer |
| Arrow keys | Navigate within menus, tabs, radio groups |
| Home / End | Jump to first/last item in a list or menu |

---

## Semantic HTML Requirements

- Use `<button>` for actions, `<a>` for navigation — never a `<div>` with onClick
- All form inputs must have an associated `<label>` (not just placeholder text)
- Use heading hierarchy correctly — only one `<h1>` per page
- Use `<nav>` for navigation, `<main>` for primary content, `<footer>` for footer
- Use `<ul>` / `<ol>` for lists of items
- Images: meaningful `alt` text always; `alt=""` for decorative images

---

## Screen Reader Requirements

- `aria-label` required on icon-only buttons
- `aria-expanded` on toggleable elements (accordion, dropdown)
- `aria-live="polite"` on dynamic content updates (toasts, form errors)
- `aria-busy="true"` during loading states
- `role="dialog"` + `aria-labelledby` on all modals
- `aria-describedby` on form inputs with helper or error text

---

## Motion & Animation

- All animations must respect `prefers-reduced-motion: reduce`
- Use motion tokens for duration/easing — never hardcode
- Implement globally:

```tsx
const prefersReduced = useReducedMotion()
const duration = prefersReduced ? 0 : motionTokens.duration.normal
```

- No content should flash more than 3 times per second (seizure risk)
