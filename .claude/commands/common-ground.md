# /common-ground

Surface all assumptions before starting work. Run at the start of any complex session.

## Instructions

Before writing a single line of code, declare your current understanding of:

**Project**
- What is this project and who uses it?
- What is the current phase (from PLAN.md)?
- What was done in the last session?

**Task**
- What do you think the current task involves?
- Which files do you think are relevant?
- What approach do you think makes most sense?

**Constraints**
- What stack and patterns are we using?
- What tokens and naming conventions apply?
- What should not be touched?

**Unknowns**
- What are you uncertain about?
- What would you need clarified before starting?

I will correct anything wrong before any code is written.
This is not optional — misaligned assumptions waste more time than this check takes.
