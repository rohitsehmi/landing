# /plan

Create a detailed implementation plan for $ARGUMENTS before writing any code.

## Instructions

Think through $ARGUMENTS carefully. Produce a plan with:

**1. Understanding**
- What exactly needs to be built?
- Who uses it and in what context?
- What does done look like?

**2. Approach**
- What is the proposed implementation strategy?
- Which files will be created or modified?
- What are the key decision points?

**3. Risks & edge cases**
- What could go wrong?
- What edge cases need handling?
- What dependencies or blockers exist?

**4. Steps**
Ordered list of concrete steps. Each step should be:
- Small enough to complete and verify independently
- Specific about which file or function is affected
- Clear about what the expected output is

**5. Questions**
- What needs clarification before starting?

DO NOT write any code yet.
Wait for explicit approval of the plan before proceeding.
If the plan changes during implementation, update it and flag the change.
